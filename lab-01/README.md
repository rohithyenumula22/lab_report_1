## Objective

The objective of this lab is to understand the fundamentals of backend web development using Node.js and Express.js. We first set up a basic Node.js project and create a minimal HTTP server using the built-in `http` module (`plain-server.js`). Then, we build a structured web server using Express.js (`server.js`) that handles multiple routes, returns plain text and JSON responses, logs status codes, and handles unknown routes with a proper 404 Not Found response.

- **`package.json`**: The project configuration file that stores project metadata (name, version, scripts) and lists required dependencies (`express`). It acts as a recipe to rebuild the project environment.

- **`server.js`**: Demonstrates the Express.js framework, simplifying routing, JSON handling, middleware execution, and 404 response handling.

## How to Run

### 1. Running the Express Server (Main Project)

To run the Express web server:

```bash
node server.js
```

Or using the npm start script:

```bash
npm start
```

The server will start and print:
```text
Server running at http://localhost:3000
```

Open your browser and navigate to:
- **Home Route:** [http://localhost:3000](http://localhost:3000)
- **About Route:** [http://localhost:3000/about](http://localhost:3000/about)
- **Time Route:** [http://localhost:3000/time](http://localhost:3000/time)

## Viva Questions

### 1. What is Node.js?
Node.js is an open-source, cross-platform JavaScript runtime environment built on Chrome's V8 engine. It allows developers to run JavaScript code on the server side, outside of a web browser.

### 2. What is Express.js?
Express.js is a fast, unopinionated, and minimalist web framework for Node.js. It simplifies backend development by providing clean abstractions for routing, middleware handling, and HTTP request/response management.

### 3. What is package.json?
`package.json` is the configuration and manifest file of a Node.js project. It contains project metadata (such as project name, version, and start scripts) and records the project's dependencies and their version ranges.

### 4. What is node_modules?
`node_modules` is a directory created automatically by npm when you run `npm install`. It contains all the installed code files of the third-party libraries and packages that the project depends on.

### 5. Difference between package.json and node_modules?
- **`package.json`** is a small, human-readable text file that lists package names and versions like a shopping list or blueprint. It is committed to version control (Git).
- **`node_modules`** is the actual directory containing all the downloaded code files for those packages. It is very large and is never committed to Git.

### 6. What does app.listen() do?
`app.listen()` binds the application to a specified network port (e.g., 3000) and starts listening for incoming client HTTP requests.

### 7. What are request and response?
- **Request (`req`)**: An object that represents the incoming HTTP request from the client. It contains details like the HTTP method, URL, headers, query parameters, and request body.
- **Response (`res`)**: An object that represents the outgoing HTTP response from the server. It provides methods like `.send()`, `.json()`, and `.status()` to send data and status codes back to the client.

### 8. What is an HTTP GET request?
An HTTP GET request is an HTTP method used by a client (such as a web browser) to request or fetch data from a server without modifying any server-side data.

### 9. What is status code 200?
HTTP Status Code `200 OK` indicates that the client's request was successfully received, understood, and processed by the server.

### 10. What is status code 404?
HTTP Status Code `404 Not Found` indicates that the server cannot find the requested URL path or resource.

### 11. Why do we use new Date()?
`new Date()` is a JavaScript constructor that creates a new Date object initialized with the current date and exact system time at the moment of execution.

### 12. What does app.get() do?
`app.get()` is a routing method in Express used to handle HTTP GET requests directed to a specific route or URL path.

### 13. Why do we use express()?
`express()` is the top-level function exported by the Express library. Calling `express()` creates and initializes a new Express application instance (`app`) with all built-in routing and middleware capabilities.

### 14. What is npm?
npm (Node Package Manager) is the default package manager for Node.js. It enables developers to install, share, update, and manage external open-source packages and dependencies in their projects.

## Notes / Problems Faced

### Problem 1:
**Port 3000 was already in use.**
- **Symptoms:** `Error: listen EADDRINUSE: address already in use :::3000`
- **Solution:** Terminate any running process using port 3000 (e.g., stop the previously running Node.js server in the terminal with `Ctrl + C`), or change the `PORT` variable to an available port (e.g., `3001` or `5000`).

### Problem 2:
**Accidentally committing node_modules to Git.**
- **Symptoms:** Very large repository size and slow git push times.
- **Solution:** Add `node_modules/` to the `.gitignore` file before committing so Git ignores the dependencies directory.
